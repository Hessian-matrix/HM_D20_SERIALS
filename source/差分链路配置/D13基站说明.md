# D13基站说明

D13 是 D20 LoRa 场景下的配套基站设备，也可按产品能力作为移动站使用。本文仅说明其作为基站时的安装和使用方法。

## 设备用途

D13 基站负责接收卫星信号并生成差分数据，通过 LoRa 链路发送给 D20 移动站。D20 接收到差分数据后完成 RTK 解算。该设备支持一对一和一对多差分数据传输，LoRa 通信距离可达约 6 公里，具体表现受环境和天线架设条件影响。

## 适用场景

- 园区机器人。
- 农机作业。
- 低空无人机。
- 临时测量和固定区域高精度定位。

## 安装要求

| 项目 | 要求 |
| --- | --- |
| 安装位置 | 开阔、无遮挡、尽量远离高楼和树木 |
| 固定方式 | 三脚架加支杆固定，保持设备稳定 |
| 天线安装 | 蘑菇头天线和 LoRa 数据天线需牢固安装 |
| 供电方式 | 建议 12V 直流外部供电，电池供电时注意电压监测 |
| 工作状态 | 上电后保持静止，不要移动基站 |

## 安装步骤

1. 选择开阔地面并架设三脚架。
2. 安装支杆和垫片，固定好结构。
3. 将蘑菇头天线安装到支杆顶部。
4. 安装 LoRa 数据天线，并调整到合适朝向。
5. 将 D13 主机固定在支架上。
6. 按接线要求完成供电后上电。

## 参数说明

D13 的 LoRa 相关参数出厂已锁定，不支持二次配置。串口波特率、数据刷新率和协议输出项可通过 NavStarTool 进行配置。

## 使用提示

- 基站上电后不要移动位置。
- 基站与移动站之间应尽量保持视距。
- 现场如有强电磁干扰、金属遮挡或高压线路，应优先调整站点位置。
- 若需检查输出，可通过 NavStarTool 读取定位状态和串口输出。
