# 4G差分链路配置

4G 版本通过蜂窝网络连接 CORS/NTRIP 服务，由 D20 内部 4G 模块接收差分数据并参与 RTK 解算。使用前需要写入 CORS/NTRIP 账号。

## 准备工作

- D20 4G 版本。
- 已开通数据流量的 SIM 卡。
- 4G 外置天线。
- 具有数据传输功能的 USB Type-C 线。
- JR_NTRIP_Config_Tool_V1.2 PC 端工具。
- CORS/NTRIP 账号信息，包括服务器地址、端口、挂载点、账号和密码。

## 配置步骤

1. 将 SIM 卡按正确方向装入 D20 侧面 SIM 卡槽。
2. 安装 4G 外置天线。
3. 使用 Type-C 数据线连接 PC 和 D20 底部 Type-C 接口。
4. 打开 JR_NTRIP_Config_Tool_V1.2。
5. 点击 `Auto-Select Target Device` 自动选择配置端口。
6. 点击连接，确认底部日志区域显示连接成功。
7. 在 `NTRIP Server Configuration` 区域填写 CORS/NTRIP 账号信息。
8. 点击 `Send Config 1 (Server Settings)` 写入配置。
9. 日志区域返回 `OK` 后，配置完成。

## 差分状态验证

完成配置后，将 D20 通过 8Pin 线缆接入目标设备并上电。4G 版本首次上电到输出固定解通常约 45 秒。若长时间无法进入固定解，请优先检查 SIM 卡状态、网络覆盖、CORS 账号和天空视野。
