# LoRa差分链路配置

LoRa 版本通过本地基站向 D20 移动站发送差分数据，由移动站完成 RTK 解算。该方式不依赖公网，但需要保证基站架设稳定、LoRa 链路可靠。

## 准备工作

- D20 LoRa 移动站。
- 配套 LoRa 基站。
- 移动站和基站的 LoRa 天线。
- 基站供电设备，例如充电宝或稳定 5V 电源。
- 用于接收 D20 串口数据的飞控、主控或 PC。

## 基站架设

1. 将基站放置在天空视野开阔的位置。
2. 使用稳定支架固定基站，建议离地约 1 米。
3. 给基站接入 5V 电源。
4. 基站上电后不要移动位置。
5. 确认移动站和基站之间无遮挡或弱遮挡。

## 移动站连接

1. 将 LoRa 天线安装到 D20 移动站通信天线接口。
2. 通过 8Pin 线缆给 D20 供电，并连接串口 TX/RX。
3. 在上位机或目标设备中确认 D20 持续输出与固件版本匹配的定位数据。
4. 等待移动站接收差分数据并进入固定解。

LoRa 版本首次上电进入固定解通常需要 1 到 3 分钟。若固定解不稳定，应优先检查基站位置、移动站天线安装、基站供电和 LoRa 链路遮挡。
