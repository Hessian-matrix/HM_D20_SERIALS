# 快速开始

本页用于放置 HM_D20_SERIALS 文档的最短上手流程。后续补充真实内容时，建议按
“准备硬件 -> 连接设备 -> 确认串口 -> 配置 RTK -> 验证输出”的顺序组织。

## 准备工作

- HM_D20 设备与供电线缆。
- RTK 天线、基站或网络差分源。
- Linux 主机或调试终端。
- 串口转接线或 USB 转串口模块。

## 基本流程

1. 确认设备供电和天线连接正常。
2. 将 HM_D20 串口连接到调试主机。
3. 在主机上确认串口设备节点，例如 `/dev/ttyUSB0`。
4. 使用串口工具打开设备，记录波特率、数据位、停止位和校验位。
5. 根据 RTK 章节配置差分数据输入，并确认定位状态输出。
