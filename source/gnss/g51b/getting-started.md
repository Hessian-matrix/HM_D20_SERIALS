# HM-G51B 快速开始

:::{admonition} 本页目标
:class: page-summary

完成 **HM-G51B** 的供电、UART 连接和首次独立 GNSS 定位验证。接收机模组支持 L1 频段信号处理，通过 UART 输出 UBX-NAV-PVT，默认波特率为 `115200`。
:::

:::{note} 产品边界
G51B 提供独立 GNSS 定位，不需要 CORS/NTRIP 或 D13 基站。需要厘米级定位时，应选择 D20 或 D13 系列。完整参数见[产品对比与资料](../../products/comparison.md)。
:::

## 准备设备

- G51B 接收机模组。
- 4.0–5.5 V 电源，典型 5 V。
- 与 G51B 接口电平兼容的 USB 转 UART 模块，或目标设备 UART 串口。
- PC 端 {ref}`NavStarTool <software-tools>` 上位机。
- 能够保证天空视野的安装位置。

## 连接供电和串口

HM-G51B 使用 6-pin MX1.25 mm 接口，提供电源、UART 和磁力计 I2C 信号，不提供 PPS 引脚。按随产品提供的接口资料完成连接：

- 供电范围为 4.0–5.5 V，典型 5 V；上电前确认电压和极性。
- UART TX/RX 交叉连接，并与 USB 转 UART 模块或目标设备共地。
- UART I/O 电平以交付版本的接口资料为准。

## 安装位置

G51B 需要接收 GNSS 卫星信号。安装时应尽量保证天线朝向天空，避开金属遮挡、高楼、树木和强电磁干扰区域。

在无人机、车载或资产定位终端中使用时，应优先将天线布置在设备上方或外壳开阔位置，避免被电池、金属结构件或大功率无线模块遮挡。

## 连接上位机

1. 下载并打开 {ref}`NavStarTool <software-tools>`。
2. 选择 G51B 对应的串口号。
3. 波特率选择 `115200`。
4. 点击连接。
5. 查看卫星数、经纬高、定位状态和 UBX-NAV-PVT 数据输出。

## 验证定位输出

### 首次定位

G51B 热启动时间约 1 秒，冷启动时间约 28 秒。首次上电或长时间断电后，定位时间可能受天空视野、卫星环境和安装位置影响。

### 输出检查

正常工作时，上位机或目标设备中应持续接收到定位数据。若无法获得稳定定位，应优先检查以下项目：

- 供电电压是否稳定。
- TX/RX 是否交叉连接。
- 串口波特率是否为 `115200`。
- 天线位置是否开阔。
- 设备附近是否存在明显遮挡或强干扰。

:::{admonition} 首次使用完成判据
:class: success-check

上位机或目标设备持续接收到 UBX-NAV-PVT 定位数据，经纬度、高程和定位状态正常更新。
:::

## 配置管理

需要修改输出频率或消息项时，先确认 UBX-NAV-PVT 输出要求，再使用配套工具配置；PVT 最高更新率为 20 Hz。
