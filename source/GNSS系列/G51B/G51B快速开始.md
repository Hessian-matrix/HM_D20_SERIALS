# G51B快速开始

G51B 是紧凑型单频 GNSS 定位模组，支持 L1 频段信号处理。模组通过 TTL 电平 UART 输出 PVT 定位数据，默认波特率为 `115200`，适合接入飞控、车载设备、资产定位终端或其他嵌入式主控。

## 使用前确认

### 确认产品能力

G51B 为单频 GNSS 模组，支持 GPS L1、北斗 B1、Galileo E1、QZSS L1 和 GLONASS G1。模组具备 120 个跟踪通道，最高支持 20 Hz 更新率，定位精度为 1.5 m CEP。

G51B 不属于 RTK 差分定位产品，不需要配置 CORS/NTRIP 账号，也不需要接入 D13 基站。需要厘米级定位时，应选择 D20 或 D13 等 RTK 系列产品。

### 确认接口

G51B 使用 TTL 电平 UART 输出定位数据，默认协议为 PVT，默认波特率为 `115200`。

模组引脚定义如下：

| 引脚 | 名称 | 说明 |
| --- | --- | --- |
| 1 | SDA | I2C 数据 |
| 2 | GND | 电源地 |
| 3 | RX | UART 接收 |
| 4 | TX | UART 发送 |
| 5 | VCC | 5V 电源输入 |
| 6 | SCL | I2C 时钟 |

## 准备设备

- G51B 模组。
- 稳定 5V 电源。
- USB 转 TTL 模块，或目标设备 UART 串口。
- PC 端 NavStarTool 上位机。
- 能够保证天空视野的安装位置。

## 连接供电和串口

### 供电要求

G51B 工作电压范围为 4.0V 到 5.5V，典型供电为 5V。上电前应确认供电极性和电压范围，避免过压或反接。

### 串口接线

首次调试建议使用 USB 转 TTL 模块连接 PC：

1. G51B VCC 接 5V。
2. G51B GND 接电源地，并与 USB 转 TTL 共地。
3. G51B TX 接 USB 转 TTL RX。
4. G51B RX 接 USB 转 TTL TX。

接入目标设备时，同样需要保证 TX/RX 交叉连接，并保持 GND 共地。

## 安装位置

G51B 需要接收 GNSS 卫星信号。安装时应尽量保证天线朝向天空，避开金属遮挡、高楼、树木和强电磁干扰区域。

在无人机、车载或资产定位终端中使用时，应优先将天线布置在设备上方或外壳开阔位置，避免被电池、金属结构件或大功率无线模块遮挡。

## 连接上位机

1. 打开 NavStarTool。
2. 选择 G51B 对应的串口号。
3. 波特率选择 `115200`。
4. 点击连接。
5. 查看卫星数、经纬高、定位状态和原始 PVT 数据输出。

## 验证定位输出

### 首次定位

G51B 热启动时间约 1 秒，冷启动时间约 28 秒。首次上电或长时间断电后，定位时间可能受天空视野、卫星环境和安装位置影响。

### 输出检查

正常工作时，上位机或目标设备中应持续接收到定位数据。若无法获得稳定定位，应优先检查以下项目：

- 供电电压是否稳定。
- TX/RX 是否交叉连接。
- 串口波特率是否为 `115200`。
- 天线位置是否开阔。
- 设备附近是否存在明显遮挡或强干扰。

## 配置管理

G51B 支持通过配置消息修改部分参数。修改后的配置在掉电或复位前保持有效；如果配置已保存到备份 RAM，则在备份电源不断开的情况下可以保留。

需要修改输出频率、协议输出项或其他接收机参数时，可通过 NavStarTool 或接收机协议文档进行配置。
