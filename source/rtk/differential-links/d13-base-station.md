# LoRa 基站架设

:::{admonition} 本页目标
:class: page-summary

完成 LoRa 套件中**专用 D13 基站**的安装、供电与稳定架设。该基站不单独销售，也不作为移动站使用；移动站连接见[LoRa 移动站连接](lora.md)。
:::

## 设备用途

专用 D13 LoRa 基站负责接收卫星信号并通过 LoRa 链路向 D20 或 D13 移动站发送内部差分数据。基站和移动站出厂默认配对，上电自动连接。

- 工作频率：默认 915 MHz。
- 拓扑：一个局部场景只允许一个基站，可一对一或一对多，最多连接 4096 个移动站，不支持多对多。
- 距离：最远约 6 km。

## 适用场景

- 园区机器人。
- 农机作业。
- 低空无人机。
- 临时测量和固定区域高精度定位。

## 安装要求

| 项目 | 要求 |
| --- | --- |
| 安装位置 | 开阔、无遮挡、尽量远离高楼和树木 |
| 固定方式 | 三脚架加支杆固定，保持设备稳定 |
| 天线安装 | D13 基站和 LoRa 数据天线需牢固安装 |
| USB 连接 | 使用配套的封装 4-pin USB 线缆；接 USB 电源可直接供电，接电脑可供电并进行 USB 串口通信 |
| 工作状态 | 上电后保持静止，不要移动基站 |

## 安装步骤

1. 选择开阔地面并架设三脚架。
2. 安装支杆和垫片，固定好结构。
3. 将专用 D13 LoRa 基站硬件固定在支杆顶部。
4. 连接基站外置 LoRa 天线，并调整到合适朝向。
5. 检查基站本体、支杆和三脚架均已可靠固定。
6. 将配套 USB 线缆连接基站，再接入 USB 电源；需要查看基站数据时可直接连接电脑进行 USB 串口通信。
7. 上电后保持基站位置不变；如果移动过基站，应重新上电。

:::{admonition} 提示
:class: tip

LoRa 基站和移动站出厂默认配对，上电自动连接。差分数据在 LoRa 链路内部传输，不需要用户配置外部差分协议。
:::

:::{warning} 只使用配套 USB 线缆
基站内部接口线不向用户开放。不要拆开线缆、改接内部导线或使用非配套转接线，以免因错误供电或信号线误接损坏设备。
:::

## 使用提示

- 基站上电后不要移动位置。
- 基站与移动站之间应尽量保持视距或弱遮挡。
- 现场如有强电磁干扰、金属遮挡或高压线路，应优先调整站点位置。
- 同一区域不要同时开启多个基站。

:::{admonition} 基站架设完成判据
:class: success-check

基站位于开阔位置，结构、外置 LoRa 天线和供电连接牢靠；上电后位置保持不变，同一区域没有开启其他基站。
:::

完成架设后，继续执行[LoRa 移动站连接](lora.md)。
