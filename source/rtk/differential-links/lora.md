# LoRa 移动站连接

:::{admonition} 本页目标
:class: page-summary

在专用 D13 LoRa 基站完成架设后，连接 **D20 或 D13 移动站**并验证 RTK 固定解。HM-D20-LoRa 和 HM-D13-LoRa 均按包含基站及配件的套件交付。
:::

## 准备工作

- D20 LoRa 或 D13 LoRa 移动站。
- 套件内的专用 D13 LoRa 基站硬件及配件。
- D20 移动站和 D13 基站使用的 LoRa 天线；D13 移动站天线内置。
- 基站供电设备，例如充电宝或 5 V ±0.5 V 电源。
- 用于接收移动站串口数据的飞控、主控或 PC。

## 基站前提

专用 D13 LoRa 基站硬件随套件提供，不单独销售，也不作为移动站使用。基站和移动站出厂默认配对，上电自动连接。开始连接移动站前，先完成[LoRa 基站架设](d13-base-station.md)。

:::{important} 开始前确认
基站已经稳定架设并保持静止；同一区域只开启一个基站；移动站与基站使用套件内的出厂配对组合。
:::

## 移动站连接

1. 使用 D20 移动站时，将 LoRa 天线安装到 SMA 接口；D13 移动站使用内置 LoRa 天线。
2. 按[D20 接口](../operation/d20-wiring.md)或[D13 接口](../operation/d13-wiring.md)连接移动站供电和 UART。
3. 确认 D13 基站已上电并保持静止。
4. 确认移动站与基站之间尽量无遮挡或弱遮挡。
5. 在上位机或目标设备中确认移动站持续输出与固件匹配的定位数据。
6. 等待移动站自动接收差分数据并进入固定解。

## 状态验证

按[RTK 状态与固定解验证](../operation/rtk-fixed-validation.md)检查移动站的定位输出和解状态。

若固定解不稳定，优先检查基站是否移动、移动站天线、基站供电、LoRa 链路遮挡和天空视野。

:::{admonition} LoRa 差分链路完成判据
:class: success-check

移动站定位数据持续输出，并在开阔环境进入 **RTK 固定解**。
:::
