# RTK 配置

本页用于记录 RTK 参数配置、差分源配置和现场验证步骤。

## 配置项模板

| 配置项 | 推荐值 | 说明 |
| --- | --- | --- |
| 差分源类型 | 后续补充 | 例如基站串口、NTRIP、网络转发 |
| 坐标输出 | 后续补充 | 例如 WGS84、ENU、机体系 |
| 输出频率 | 后续补充 | 明确单位 Hz |
| 时间戳来源 | 后续补充 | 明确 GNSS 时间、系统时间或主机时间 |

## 验证步骤

1. 记录天线安装位置和朝向。
2. 确认差分数据持续输入。
3. 观察定位状态是否进入固定解。
4. 记录静态点位漂移和动态轨迹连续性。
5. 保存原始串口日志，便于问题复现。
