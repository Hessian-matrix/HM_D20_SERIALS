# D13基站系统介绍

D13 是一款多频多系统 GNSS RTK 定位模块，可作为 D20 LoRa 版本的配套基站使用，也可按产品能力作为移动站应用在通用定位场景中。D13 集成高精度 RTK 定位单元、多频 GNSS 天线和 LoRa 通信模块，支持基站向一个或多个移动站发送差分数据。

D13 支持 GPS、北斗、GLONASS、Galileo、QZSS、IRNSS（NavIC）等卫星导航系统。在 LoRa 差分链路中，D13 负责接收卫星信号、生成差分数据，并通过 LoRa 链路发送给 D20 移动站。D20 接收差分数据后完成 RTK 解算。

## 系统组成

| 组成 | 说明 |
| --- | --- |
| D13 主机 | 集成 RTK 定位单元、多频 GNSS 天线和 LoRa 通信模块 |
| 蘑菇头天线 | 用于 GNSS 信号接收，安装在支杆顶部 |
| LoRa 数据天线 | 用于基站和移动站之间的差分数据传输 |
| 供电线缆 | 连接 D13 与外部电源 |
| 三脚架和支杆 | 用于现场架设，需用户自备 |

## 工作方式

D13 作为基站时的典型链路如下：

1. D13 接收 GNSS 卫星信号。
2. D13 生成 RTCM V3.x 差分数据。
3. D13 通过 LoRa 链路向 D20 移动站发送差分数据。
4. D20 移动站完成 RTK 解算并向下游设备输出定位结果。

D13 支持一对一和一对多差分数据传输，适合一个基站覆盖多个移动终端的作业场景。LoRa 通信距离可达约 6 公里，实际距离受天线架设高度、遮挡、干扰和现场环境影响。

## 主要能力

| 项目 | 说明 |
| --- | --- |
| 卫星系统 | GPS、北斗、GLONASS、Galileo、QZSS、IRNSS（NavIC） |
| 差分数据 | RTCM V3.x |
| 输出协议 | NMEA-0183 |
| 典型输出语句 | GGA、RMC、VTG、GSA、GSV |
| 默认波特率 | 115200 bps |
| 更新频率 | 默认 1Hz，最高可配置到 20Hz |
| RTK 精度 | 水平 0.01m + 1ppm，垂直 0.015m + 1ppm |
| 冷启动时间 | 小于 20s，首次冷启动约 45s |
| 典型初始化时间 | 小于 5s |
| 工作温度 | -40°C 到 +85°C |

## 使用场景

D13 适合固定区域内的本地差分链路场景，例如：

- 园区机器人。
- 低空无人机。
- 精准农业。
- 大地测绘和航道测绘。
- 智能驾驶测试。
- 海洋测量。

## 配置说明

D13 的 LoRa 相关参数出厂已锁定，不支持用户二次配置。串口波特率、数据刷新率和协议输出项可通过 NavStarTool 上位机配置。

D13 作为基站时的现场安装、供电和注意事项，请参考 [D13基站说明](../差分链路配置/D13基站说明.md)。
