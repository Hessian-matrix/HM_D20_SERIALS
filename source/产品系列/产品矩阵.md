* - 产品形态
  - 四臂螺旋天线 + RTK 模组 + CORS 通讯模块高度集成的一体化移动站
  - 高可靠性蘑菇头天线 + RTK 模组 + 差分通讯模块，可作为基站或移动站使用
  - 陶瓷天线 + GNSS 模组
* - 核心定位
  - 尺寸敏感场景输出高精度 RTK 定位结果
  - 各种场景提供可靠的定位输出，可作为基站
  - 尺寸敏感、低成本条件下可提供 GNSS 可靠定位结果
* - 差分链路
  - 支持 4G CORS/NTRIP 或 LoRa 差分链路
  - 4G 移动站支持 4G CORS，LoRa 版本支持 LoRa 组网差分链路
  - 无
* - 协议/固件
  - 无人机版主要输出 UBX/u-blox；地面版主要输出 NMEA
  - 支持 NMEA-0183，差分数据为 RTCM V3.x
  - UBX
* - 典型能力
  - L1 + L5 双频 RTK，适配飞控、机器人主控、Viobot2 和 PC 上位机
  - L1 + L5 双频 RTK，支持一对一或一对多差分数据传输，LoRa 通信距离可达约 5 公里
  - L1 + L5 双频 GNSS
* - 适用场景
  - 无人机、机器人、通用高精度定位终端
  - 本地基站差分链路、固定区域多移动站作业、测绘、精准农业
  - 无人机定位、GPS定位器

  - {doc}`G51B </GNSS系列/G51B/index>`
