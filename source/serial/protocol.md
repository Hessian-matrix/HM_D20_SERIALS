# 串口协议

本页用于放置 HM_D20 串口数据帧格式、命令集合和解析规则。

## 帧格式

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| Header | 后续补充 | 帧头或同步字 |
| Message ID | 后续补充 | 消息类型 |
| Payload Length | 后续补充 | 载荷长度 |
| Payload | 后续补充 | 消息载荷 |
| Checksum | 后续补充 | 校验字段 |

## 解析约定

- 明确大小端。
- 明确整数、浮点数、角度、距离和时间戳单位。
- 明确坐标系定义和姿态四元数顺序。
- 明确异常帧、丢帧、校验失败时的处理策略。
