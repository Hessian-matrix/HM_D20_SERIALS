# 串口通信概览

本章用于整理 HM_D20 与外部主机之间的串口连接、串口参数和调试方法。

## 建议记录的信息

| 项目 | 内容 |
| --- | --- |
| 设备节点 | 例如 `/dev/ttyUSB0`、`/dev/ttyS0` |
| 波特率 | 后续补充实际值 |
| 数据位 | 后续补充实际值 |
| 停止位 | 后续补充实际值 |
| 校验位 | 后续补充实际值 |
| 流控 | 后续补充实际值 |

## 调试命令示例

```bash
dmesg --follow
ls -l /dev/ttyUSB*
```

串口工具可以根据团队习惯选择 `picocom`、`minicom` 或自研调试脚本。正式内容中应明确
每个命令对应的主机系统、设备节点和串口参数。
