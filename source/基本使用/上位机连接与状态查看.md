# 上位机连接与状态查看

D20 可使用 NavStarTool 上位机查看卫星信息、定位状态、经纬高和原始协议输出。首次使用或现场排查时，建议先通过上位机确认设备输出正常，再接入飞控、机器人主控或 Viobot2。

## 准备工作

- NavStarTool PC 端软件。
- D20 主机。
- USB 转 TTL 模块。
- 5V 供电。
- 已完成 4G 或 D13 基站差分链路准备。

## 连接步骤

1. 按照串口接线说明连接 D20 和 USB 转 TTL 模块。
2. 将 USB 转 TTL 模块接入 PC。
3. 打开 NavStarTool。
4. 选择 D20 对应的串口号。
5. 波特率选择 `115200`。
6. 点击连接。

连接成功后，软件中会持续显示卫星信息、定位信息、经纬高、固定解状态和原始协议输出。

![NavStarTool主界面](image/navstar_main.png)

## 固定解时间

- D20 LoRa 版本首次上电后通常需要等待 1 到 3 分钟进入固定解。
- D20 4G 版本首次上电到固定解通常约 45 秒。

实际固定解时间与天空视野、差分链路质量、基站架设、4G 网络和 CORS 服务状态有关。
