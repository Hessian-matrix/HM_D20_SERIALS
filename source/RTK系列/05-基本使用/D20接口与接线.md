# D20接口与接线

本页适用于HM-D20-4G和HM-D20-LoRa移动站，说明外部接口、8-pin引脚和首次接线要求。

## 接口总览

![D20接口定义](../image/rtk_series_d20_interface.png)

| 接口 | HM-D20-4G | HM-D20-LoRa |
| --- | --- | --- |
| 8-pin GH1.25 mm | 供电、UART、PPS、磁力计SCL/SDA | 同左 |
| SMA | 外置4G天线 | 外置LoRa天线 |
| USB-C | 配置CORS/NTRIP账号 | 不需要用户配置差分账号 |

## 8-pin定义

以下顺序与上图连接器和线色标识一致。设备提供两个GND引脚。

| 信号 | 用途 | 接线要求 |
| --- | --- | --- |
| GND | 电源地 / 信号参考地 | 与电源和下游设备共地 |
| SDA | 磁力计I2C数据 | 使用磁力计时连接 |
| SCL | 磁力计I2C时钟 | 使用磁力计时连接 |
| TX | D20串口发送 | 连接外部设备RX |
| RX | D20串口接收 | 连接外部设备TX |
| 5V | 设备供电 | 接5 V ±0.5 V电源 |
| GND | 电源地 / 信号参考地 | 与电源和下游设备共地 |
| PPS | 秒脉冲输出 | 需要时间同步时连接 |

## 串口与供电边界

- 供电：5 V ±0.5 V（4.5–5.5 V）。
- 外部 UART IO 电平：3.3 V。
- 默认串口：115200 bps、8数据位、1停止位、无校验、无流控。
- 禁止直接连接RS232接口。

## 首次接线

1. 设备断电，确认电源电压和极性。
2. D20 5V接电源正极，GND接电源负极。
3. D20 TX接外部设备RX，D20 RX接外部设备TX。
4. D20 与 3.3 V UART 调试器、飞控或主控共地，并确认对方 UART 兼容 3.3 V IO 电平。
5. 仅使用定位时，SCL、SDA和PPS可以不连接。
6. 4G或LoRa天线安装牢靠后再上电。

上电后按[上位机连接与串口调试](上位机连接与串口调试.md)检查输出。

## 磁力计

D20标配QMC5883L磁力计，通过SCL/SDA连接主控。磁力计需要按目标系统的标准流程校准；安装时应尽量远离电机、电源线、大电流设备和磁性材料。
