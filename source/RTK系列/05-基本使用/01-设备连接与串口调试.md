# 设备连接与串口调试

D20 通过底部 8Pin GH1.25 接口完成供电和串口数据输出。使用 PC 调试时，可通过 USB 转 TTL 模块连接 D20；接入飞控或机器人主控时，可直接连接目标设备的 UART。

![D20连接TTL](image/d20_ttl_connection.png)

## 接线要求

- D20 供电电压为 5V，高于该电压可能损坏设备。
- D20 GND 需要与 USB 转 TTL、飞控或主控共地。
- D20 TX 连接外部设备 RX。
- D20 RX 连接外部设备 TX。
- 接线前确认外部串口电平，避免将 TTL 串口接入 RS232 电平接口。

## 串口参数

| 项目 | 参数 |
| --- | --- |
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | None |
| 流控 | None |

## Linux 下确认串口

连接 USB 转 TTL 后，可以在 Linux 主机上通过以下命令确认设备节点：

```bash
dmesg --follow
ls -l /dev/ttyUSB*
```

如果串口节点为 `/dev/ttyUSB0`，可使用串口工具观察原始输出：

```bash
picocom -b 115200 /dev/ttyUSB0
```

正常情况下，终端中应能看到持续刷新的定位数据。地面版固件主要输出 NMEA 字符串；无人机版固件主要输出 UBX/u-blox 协议数据。

## 定位数据输出要求

定位数据输出协议由固件版本决定：

- 无人机版固件：主要输出 UBX/u-blox 协议，用于 AMP、PX4 等飞控接入。
- 地面版固件：主要输出 NMEA 协议，用于 Viobot2、机器人主控或 PC 上位机接入。

地面版固件接入 Viobot2 时，建议至少开启 NMEA GGA 和 RMC。外部系统若要求更高刷新率，可在 NavStarTool 中配置 D20 的工作频率和输出语句。
