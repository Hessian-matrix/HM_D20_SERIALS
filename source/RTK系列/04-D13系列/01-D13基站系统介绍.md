# D13系列版本介绍

D13 是一款多频多系统 GNSS RTK 定位模块，集成高精度 RTK 定位单元、多频 GNSS 天线和 LoRa 通信模块。D13 可作为基站使用，也可作为移动站使用；在 4G 版本中，可通过蜂窝网络接入 CORS/NTRIP 差分服务。

## D13基站版本

D13 基站版本用于 LoRa 差分链路中的固定基站。基站负责接收 GNSS 卫星信号，生成 RTCM V3.x 差分数据，并通过 LoRa 链路发送给移动站。

### 系统组成

| 组成 | 说明 |
| --- | --- |
| D13 基站 | LoRa 差分链路中的固定基站，只能使用 D13 作为基站 |
| 蘑菇头 GNSS 天线 | 用于接收卫星信号，安装在支杆顶部 |
| LoRa 数据天线 | 用于向移动站发送差分数据 |
| 供电线缆 | 用于连接外部电源 |
| 三脚架和支杆 | 用于现场固定架设 |

### 工作方式

1. D13 基站固定架设在开阔位置。
2. D13 基站接收 GNSS 卫星信号。
3. D13 基站生成 RTCM V3.x 差分数据。
4. D13 基站通过 LoRa 链路向移动站发送差分数据。
5. 移动站接收差分数据后完成 RTK 解算，并向下游设备输出定位结果。

LoRa 差分链路中，基站只能使用 D13。移动站可以是 D20 LoRa 移动站，也可以是 D13 移动站版本。

D13 基站支持一对一和一对多差分数据传输，适合一个基站覆盖多个移动站的作业场景。需要注意的是，同一片作业区域内不允许多个基站同时运行，否则可能导致移动站接收差分数据异常或固定解不稳定。

### 使用场景

- 固定区域内的高精度定位作业。
- 园区机器人、农机和低空无人机。
- 大地测绘、航道测绘和海洋测量。
- 需要一个基站覆盖多个移动站的协同作业场景。

### 架设要求

- 基站应架设在天空视野开阔的位置，远离高楼、树木和金属遮挡。
- 基站应远离机场、高压线、变电站等强干扰区域。
- 三脚架、支杆、蘑菇头 GNSS 天线和 LoRa 数据天线应安装牢靠。
- 基站上电后应保持静止，作业过程中不要移动基站位置。
- 基站与移动站之间应尽量保持无遮挡或弱遮挡。

## D13移动站版本

D13 移动站版本用于接收 D13 基站发送的 LoRa 差分数据，并在移动站侧完成 RTK 解算。移动站输出 NMEA-0183 定位数据，可接入下游设备、PC 上位机或其他串口采集系统。

### 链路关系

| 角色 | 可用设备 | 说明 |
| --- | --- | --- |
| 基站 | D13 基站版本 | LoRa 差分链路中只能使用 D13 作为基站 |
| 移动站 | D20 LoRa 移动站 | 接收 D13 基站差分数据并输出定位结果 |
| 移动站 | D13 移动站版本 | 接收 D13 基站差分数据并输出定位结果 |

在 LoRa 差分链路中，D13 基站可以同时服务多个移动站。移动站数量和稳定性受 LoRa 链路质量、遮挡、干扰、天线安装和现场环境影响。

### 工作方式

1. D13 基站在开阔位置固定架设并上电。
2. D13 移动站安装 LoRa 数据天线并上电。
3. D13 移动站接收基站发送的 RTCM V3.x 差分数据。
4. D13 移动站完成 RTK 解算。
5. D13 移动站通过 TTL 串口输出 NMEA-0183 定位数据。

### 适用场景

- 需要 D13 作为移动端接入下游设备的高精度定位场景。
- 固定区域内多移动站协同作业。
- 测绘、精准农业、智能驾驶测试和海洋测量。

### 接入说明

D13 移动站通过 TTL 电平串口输出定位数据，默认波特率为 115200 bps。接入 PC、主控或外部串口设备时，需要保证 TX/RX 交叉连接，并保持 GND 共地。

## D13 4G版本

D13 4G 版本通过蜂窝网络接入 CORS/NTRIP 差分服务，不依赖本地 LoRa 基站。该方式适合有公网覆盖、作业区域较分散、或现场不便架设本地基站的场景。

### 工作方式

1. D13 4G 版本接收 GNSS 卫星信号。
2. 设备通过 4G 网络连接 CORS/NTRIP 服务。
3. 设备接收网络差分数据并完成 RTK 解算。
4. 设备通过 TTL 串口向下游设备输出 NMEA-0183 定位数据。

### 使用条件

- 现场需要有可用的蜂窝网络覆盖。
- 需要准备已开通数据流量的 SIM 卡。
- 需要准备可用的 CORS/NTRIP 账号。
- 需要保证 GNSS 天线处于开阔位置。

### 适用场景

- 作业区域较分散，移动范围较大的场景。
- 不方便架设 D13 本地基站的场景。
- 已有稳定 CORS/NTRIP 服务可用的场景。

## 版本对比

| 版本 | 差分数据来源 | 设备角色 | 典型输出 | 适用场景 |
| --- | --- | --- | --- | --- |
| D13 基站版本 | 自身生成 RTCM V3.x 差分数据 | LoRa 基站 | 通过 LoRa 发送差分数据 | 固定区域一对一或一对多移动站作业 |
| D13 移动站版本 | D13 基站通过 LoRa 发送差分数据 | LoRa 移动站 | NMEA-0183 定位数据 | 自建 LoRa 差分链路的移动端定位 |
| D13 4G 版本 | CORS/NTRIP 网络差分服务 | 4G 移动站 | NMEA-0183 定位数据 | 有公网覆盖、不便自建基站的高精度定位 |
