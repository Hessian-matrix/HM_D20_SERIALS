# LoRa移动站连接

HM-D20-LoRa 和 HM-D13-LoRa 均为包含专用 D13 LoRa 基站硬件及配件的套件。本页说明基站完成架设后，D20 或 D13 移动站的连接和状态验证。

## 准备工作

- D20 LoRa 或 D13 LoRa 移动站。
- 套件内的专用 D13 LoRa 基站硬件及配件。
- D20 移动站和 D13 基站使用的 LoRa 天线；D13 移动站天线内置。
- 基站供电设备，例如充电宝或 5 V ±0.5 V 电源。
- 用于接收移动站串口数据的飞控、主控或 PC。

## 基站前提

专用 D13 LoRa 基站硬件随套件提供，不单独销售，也不作为移动站使用。基站和移动站出厂默认配对，上电自动连接。开始连接移动站前，先完成[LoRa基站架设](01-D13基站说明.md)。

## 移动站连接

1. 使用D20移动站时，将LoRa天线安装到SMA接口；D13移动站使用内置LoRa天线。
2. 按[D20接口](../05-基本使用/D20接口与接线.md)或[D13接口](../05-基本使用/D13接口与接线.md)连接移动站供电和UART。
3. 确认D13基站已上电并保持静止。
4. 确认移动站与基站之间尽量无遮挡或弱遮挡。
5. 在上位机或目标设备中确认移动站持续输出与固件匹配的定位数据。
6. 等待移动站自动接收差分数据并进入固定解。

## 状态验证

按[RTK 状态与固定解验证](../05-基本使用/RTK状态与Fixed验证.md)检查移动站。普通用户无需查看内部 LoRa 链路状态；确认定位数据持续输出，并在开阔环境进入 RTK 固定解，即可判断差分通信链路正常。

若固定解不稳定，优先检查基站是否移动、移动站天线、基站供电、LoRa 链路遮挡和天空视野。
