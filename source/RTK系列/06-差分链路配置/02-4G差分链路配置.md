# 4G/CORS配置

HM-D20-4G和HM-D13-4G通过蜂窝网络连接CORS/NTRIP服务并获取差分数据。用户需要提供有流量的SIM卡、正确的CORS/NTRIP账号，并确保设备位于蜂窝网络覆盖区域；流量由用户自行管理。

## 准备工作

- HM-D20-4G 或 HM-D13-4G。
- 已开通数据流量的 SIM 卡。
- HM-D20-4G 使用的外置 SMA 4G 天线；HM-D13-4G 的 4G 天线内置。
- 具有数据传输功能的 USB Type-C 线。
- 对应产品交付的 CORS/NTRIP 配置工具；HM-D20-4G 使用 JR_NTRIP_Config_Tool_V1.2。
- CORS/NTRIP 账号信息，包括服务器地址、端口、挂载点、账号和密码。

## 产品差异

| 产品 | 4G天线 | SIM卡与配置口 |
| --- | --- | --- |
| HM-D20-4G | 外置SMA天线 | USB-C配置口位于设备底部；按交付结构安装SIM卡 |
| HM-D13-4G | 天线内置 | Nano-SIM卡槽和USB-C配置口位于顶壳内部 |

## 配置步骤

1. 按设备结构安装 SIM 卡；HM-D13-4G 使用 Nano-SIM，卡槽位于顶壳内部。
2. 使用 HM-D20-4G 时安装外置 SMA 4G 天线；HM-D13-4G 无需安装外置 4G 天线。
3. 使用 Type-C 数据线连接 PC 和设备配置口；HM-D13-4G 的配置口位于顶壳内部。
4. 打开对应产品的 CORS/NTRIP 配置工具。以下界面字段以 HM-D20-4G 使用的 JR_NTRIP_Config_Tool_V1.2 为例。
5. 点击 `Auto-Select Target Device` 自动选择配置端口。
6. 点击连接，确认底部日志区域显示连接成功。
7. 在 `NTRIP Server Configuration` 区域填写 CORS/NTRIP 账号信息。
8. 点击 `Send Config 1 (Server Settings)` 写入配置。
9. 日志区域返回 `OK` 后，配置完成。

## 差分状态验证

完成配置后，按[D20接口](../05-基本使用/D20接口与接线.md)或[D13接口](../05-基本使用/D13接口与接线.md)连接移动站并上电。

RTK首次固定时间受天空视野、蜂窝网络、CORS/NTRIP服务和现场环境影响，应按[RTK状态与Fixed验证](../05-基本使用/RTK状态与Fixed验证.md)确认结果。若无法进入Fixed，优先检查SIM卡状态、网络覆盖、CORS/NTRIP账号、4G天线和天空视野。
