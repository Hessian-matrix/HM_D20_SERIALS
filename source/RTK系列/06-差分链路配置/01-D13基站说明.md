# LoRa基站架设

D13 LoRa基站是HM-D20-LoRa和HM-D13-LoRa套件中的配套设备，不单独销售。本页只说明基站的安装、供电和现场边界；移动站连接见[LoRa移动站连接](03-LoRa差分链路配置.md)。

## 设备用途

D13基站负责接收卫星信号并通过LoRa链路向D20或D13移动站发送内部差分数据。基站和移动站出厂默认配对，上电自动连接。

- 工作频段：850–930 MHz，出厂默认915 MHz。
- 拓扑：一个局部场景只允许一个基站，可一对一或一对多，最多连接4096个移动站，不支持多对多。
- 距离：标称最远约6 km，需无遮挡视距和合适天线条件；未完成我方实测，不作为现场保证距离。

## 适用场景

- 园区机器人。
- 农机作业。
- 低空无人机。
- 临时测量和固定区域高精度定位。

## 安装要求

| 项目 | 要求 |
| --- | --- |
| 安装位置 | 开阔、无遮挡、尽量远离高楼和树木 |
| 固定方式 | 三脚架加支杆固定，保持设备稳定 |
| 天线安装 | 蘑菇头天线和 LoRa 数据天线需牢固安装 |
| 供电方式 | 通过2-pin USB供电线接入5 V ±0.5 V电源 |
| 工作状态 | 上电后保持静止，不要移动基站 |

## 安装步骤

1. 选择开阔地面并架设三脚架。
2. 安装支杆和垫片，固定好结构。
3. 将蘑菇头天线安装到支杆顶部。
4. 安装 LoRa 数据天线，并调整到合适朝向。
5. 将 D13 主机固定在支架上。
6. 连接5 V ±0.5 V电源后上电。
7. 上电后保持基站位置不变；如果移动过基站，应重新上电。

## 参数说明

LoRa基站和移动站出厂默认配对，上电自动连接。差分数据在LoRa链路内部传输，不需要用户配置外部差分协议。

## 使用提示

- 基站上电后不要移动位置。
- 基站与移动站之间应尽量保持视距。
- 现场如有强电磁干扰、金属遮挡或高压线路，应优先调整站点位置。
- 基站与移动站之间应尽量保持无遮挡或弱遮挡。
- 同一区域不要同时开启多个基站。

完成架设后，继续执行[LoRa移动站连接](03-LoRa差分链路配置.md)。
