# D13快速开始

D13 是一款多频多系统 GNSS RTK 定位模块，集成高精度 RTK 定位单元、多频 GNSS 天线和 LoRa 通信模块。D13 可作为基站，也可作为移动站，适用于固定区域高精度定位、测绘、精准农业、智能驾驶测试和海洋测量等场景。

## 主要参数

| 项目 | 参数 |
| --- | --- |
| 卫星系统 | GPS、北斗、GLONASS、Galileo、QZSS、IRNSS（NavIC） |
| 频点 | GPS L1/L5、北斗 B1/B2A/B2I、Galileo E1/E5、QZSS L1/L5、GLONASS G1、IRNSS L5 |
| 差分数据 | RTCM V3.x |
| 输出协议 | NMEA-0183 |
| 典型输出语句 | GGA、RMC、VTG、GSA、GSV |
| 默认波特率 | 115200 bps |
| 更新频率 | 默认 1Hz，最高可配置到 20Hz |
| RTK 精度 | 水平 0.01m + 1ppm，垂直 0.015m + 1ppm |
| LoRa 通信距离 | 约 6 公里，实际距离受遮挡、干扰和天线架设影响 |
| 工作电压 | 直流 4.6V 到 5.5V，典型 5.0V |
| 工作温度 | -40°C 到 +85°C |
| 尺寸和重量 | ---------- |


## 推荐使用方式

D13 主推使用“基站 + 移动站”组合。基站固定架设在开阔位置，负责接收卫星信号并生成 RTCM V3.x 差分数据；移动站接收差分数据后完成 RTK 解算，并向下游设备输出 NMEA 定位数据。

这种方式不依赖公网覆盖，适合农机、园区机器人、测绘、低空无人机和固定区域多终端协同作业。对于同一作业区域内的多个移动站，一个 D13 基站可向一个或多个移动站发送差分数据，现场部署关系清晰，后续维护也更直接。

## 硬件准备清单

### 基站侧

- D13 基站设备。
- 蘑菇头 GNSS 天线。
- LoRa 数据天线。
- 供电线缆。
- 三脚架、支杆和固定配件。
- 稳定外部电源。

### 移动站侧

- D13 移动站设备，或其他可接收 D13 差分数据的移动站设备。
- LoRa 数据天线。
- 供电线缆。
- USB 转 TTL 模块，或目标设备 UART 串口。
- PC 端 NavStarTool 上位机。

### 4G版本额外准备

- 已开通数据流量的 SIM 卡。
- CORS/NTRIP 账号信息，包括服务器地址、端口、挂载点、账号和密码。
- 4G 天线。
- 用于配置账号的 PC 工具和数据线。

## 基站架设&差分信号配置

### 基站架设

1. 选择开阔、平整、稳定的位置，尽量远离高楼、树木、金属遮挡和强电磁干扰源。
2. 展开三脚架并锁紧支腿，确认三脚架不会晃动或倾倒。
3. 将支杆固定到三脚架顶部。
4. 将蘑菇头 GNSS 天线安装到支杆顶部，并确认连接牢靠。
5. 安装 LoRa 数据天线，根据现场方向和遮挡情况调整天线姿态。
6. 固定 D13 主机，并连接供电线缆。
7. 完成全部连接后再上电。
8. 基站上电后保持静止，作业过程中不要移动三脚架、支杆或蘑菇头天线。

基站位置会直接影响移动站固定解稳定性。D13 基站上电后应等待其完成卫星搜索并开始稳定发送差分数据，首次冷启动可按约 45s 预留等待时间。若移动站无法进入固定解，优先检查基站是否开阔架设、是否被移动、LoRa 天线是否安装牢靠，以及移动站与基站之间是否存在明显遮挡。

### 4G版本配置CORS账号

4G 版本通过蜂窝网络接入 CORS/NTRIP 差分服务。使用前需要写入 CORS/NTRIP 账号信息。

1. 安装 SIM 卡和 4G 天线。
2. 使用配置数据线将设备连接到 PC。
3. 打开对应的 CORS/NTRIP 配置工具。
4. 填写服务器地址、端口、挂载点、账号和密码。
5. 写入配置并确认工具返回成功。
6. 重新上电，等待设备接入 CORS/NTRIP 服务。

4G 版本适合有公网覆盖、作业区域较分散或不方便自建基站的场景。若现场已有稳定作业区域，优先推荐使用“D13 基站 + 移动站”的 LoRa 差分方式。

## 连接上位机使用

### 硬件组装

1. 确认 GNSS 天线、LoRa 数据天线和供电线缆已经安装牢靠。
2. 移动站设备应安装在天空视野开阔的位置。
3. 基站与移动站之间应尽量保证无遮挡或弱遮挡。
4. 上电前确认电压和正负极连接。

### 硬件串口连接

D13 使用 TTL 电平串口输出定位数据。首次调试建议使用 USB 转 TTL 模块连接 PC：

1. D13 VCC 接稳定 5V 电源。
2. D13 GND 接电源地，并与 USB 转 TTL 或目标设备共地。
3. D13 TX 接 USB 转 TTL RX。
4. D13 RX 接 USB 转 TTL TX。

接入目标设备时，同样需要保证 TX/RX 交叉连接，并保持 GND 共地。

### NavStarTool连接

1. 打开 NavStarTool。
2. 选择 D13 对应的串口号。
3. 波特率默认选择 `115200`。
4. 点击连接。
5. 连接成功后查看卫星数、经纬高、定位状态和原始协议输出。

移动站正常工作时，应能持续输出 NMEA-0183 数据。进入 RTK 工作状态后，可在上位机或目标设备中观察固定解状态。若长时间无法进入固定解，应检查基站架设、Lora天线、差分链路、供电和天空视野。
