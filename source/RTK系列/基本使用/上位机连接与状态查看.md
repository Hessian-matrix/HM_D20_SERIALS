# 上位机介绍与状态查看

NavStarTool 是用于 GNSS/RTK 模块调试和状态查看的 PC 上位机软件。首次使用 D20、D13 或 G51B 时，建议先通过 NavStarTool 确认串口连接、卫星接收、定位状态和原始数据输出，再接入飞控、机器人主控或其他下游设备。

本章节只介绍软件界面认识、设备连接和状态查看。参数配置、输出语句配置和固件升级等内容，请在“参数配置和维护”章节中查看。

## 连接设备

使用 NavStarTool 连接模块前，需要准备：

- NavStarTool 上位机软件。
- D20、D13 或 G51B 模块。
- USB 转 TTL 模块，或目标设备串口。
- 稳定供电。

连接时需要保证：

1. 模块 TX 接 USB 转 TTL 的 RX。
2. 模块 RX 接 USB 转 TTL 的 TX。
3. 模块 GND 与 USB 转 TTL 或目标设备共地。
4. 模块供电电压符合对应产品要求。

打开 NavStarTool 后，选择模块对应的串口号，波特率通常选择 `115200`，然后点击连接。连接成功后，主界面会开始刷新卫星、轨迹、信号强度和 NMEA 信息。

## 串口控制台

NavStarTool 提供串口控制台，可通过菜单栏 `Receiver -> Console` 打开。串口控制台主要用于观察串口收发情况，也可以作为串口调试窗口使用。

控制台窗口支持 Hex 和 ASCII 显示方式。普通状态查看时，用户只需要确认窗口中是否有持续数据输出；如果没有数据，应优先检查串口号、波特率、TX/RX 接线、供电和共地。

## 主界面四个显示窗口

NavStarTool 主界面通常分为四个主要显示区域，用于从不同角度查看模块当前状态。

| 窗口 | 主要内容 | 查看重点 |
| --- | --- | --- |
| 星空图 | 显示可视卫星数量、卫星方位角和高度角，以及 HDOP、VDOP 等信息 | 判断天空视野和参与解算的卫星分布 |
| 轨迹图 | 显示最近定位点轨迹和当前定位点 | 判断定位点是否持续刷新、轨迹是否明显漂移 |
| 卫星 CN0 | 显示不同卫星和频点的信号强度 | 判断卫星信号质量，灰色背景表示当前卫星未参与定位解算 |
| NMEA 信息 | 实时显示 GGA、GSA、GSV、RMC 等定位语句和关键定位数值 | 查看经纬度、高程、定位状态、卫星数和原始输出 |

星空图中，参与定位解算的卫星和未参与解算的卫星会用不同颜色区分。轨迹图中，当前定位点会随模块输出持续更新。NMEA 信息窗口是确认模块是否正常输出定位数据的主要位置。

## 查看模块输出数据

连接成功后，重点查看以下信息：

- 卫星数是否持续刷新。
- 经纬度和高程是否有有效数值。
- NMEA 信息窗口是否持续输出定位语句。
- 轨迹图中当前定位点是否更新。
- 卫星 CN0 是否有稳定信号强度。
- RTK 产品是否进入 Float、Fixed 或 3D RTK 等状态。

如果模块没有输出数据，先检查串口连接和供电；如果有数据但定位状态不稳定，优先检查天线安装位置、天空视野、差分链路和现场遮挡情况。
