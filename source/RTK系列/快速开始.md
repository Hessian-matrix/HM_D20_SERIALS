# 快速开始

本页给出 D20 首次上电到确认 RTK 输出的最短流程。完整配置请继续阅读后续章节。

## 准备工作

- D20 主机、8Pin 线缆和通信天线。
- 5V 供电，电流建议不低于 0.5A。
- USB 转 TTL 模块或目标设备串口。
- PC 端 NavStarTool 上位机。
- 4G 版本需要可用 SIM 卡和 CORS/NTRIP 账号。
- LoRa 版本需要配套基站和稳定供电。

## 连接设备

1. 将 4G 或 LoRa 天线旋入设备通信天线接口。
2. 通过 8Pin 接口连接 5V 供电、GND、串口 TX 和串口 RX。
3. 使用 USB 转 TTL 模块连接 PC 时，注意 D20 的 TX 接 USB 转 TTL 的 RX，D20 的 RX 接 USB 转 TTL 的 TX。
4. 打开 NavStarTool，选择实际串口号，波特率选择 `115200`，点击连接。
5. 连接成功后，在上位机中查看卫星数、经纬高、定位状态和原始协议输出。

## 差分链路

### 4G 版本

1. 插入已开通数据流量的 SIM 卡。
2. 使用 JR_NTRIP_Config_Tool 通过底部 Type-C 接口写入 CORS/NTRIP 账号。
3. 重新上电后等待设备接入差分服务。
4. 首次上电到固定解通常约 45 秒，实际时间受网络、卫星环境和 CORS 服务影响。

### LoRa 版本

1. 将 D13 基站固定在开阔位置，建议离地约 1 米。
2. 基站上电后保持静止，不要中途移动。
3. D20 移动站上电后等待接收基站差分数据。
4. 首次上电进入固定解通常需要 1 到 3 分钟，实际时间受基站架设和天空视野影响。

## 验证输出

正常工作时，NavStarTool 中应持续刷新定位数据、卫星信息和定位状态。接入外部系统前，请先确认 D20 固件版本与目标系统匹配：无人机飞控使用无人机版固件，主要输出 UBX/u-blox 协议；Viobot2 和地面机器人使用地面版固件，主要输出 NMEA 协议。
