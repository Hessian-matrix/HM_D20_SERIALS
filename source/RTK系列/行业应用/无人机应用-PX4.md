# 无人机应用-PX4

D20 接入 PX4 时，应使用 D20 无人机版固件。无人机版固件主要通过 GPS 串口向 PX4 输出 UBX/u-blox 协议定位数据。接入飞控前，建议先使用 NavStarTool 确认 D20 输出正常。

## 固件版本

| 项目 | 要求 |
| --- | --- |
| D20 固件 | 无人机版固件 |
| 主要输出协议 | UBX/u-blox 协议 |
| 差分链路 | 按现场条件选择 4G 版本或 LoRa 版本 |

## 硬件连接

1. D20 安装在机体顶部开阔位置。
2. D20 TX 接 PX4 GPS 接口 RX。
3. D20 RX 接 PX4 GPS 接口 TX。
4. D20 GND 接 PX4 GND。
5. 确认接口供电为 5V，且电流能力满足设备要求。

## 参数建议

PX4 侧需要启用对应 GPS 串口，并将波特率设置为 `115200`。不同飞控硬件的 GPS 口名称不同，请以实际硬件和 QGroundControl 中的串口参数为准。

| 项目 | 建议 |
| --- | --- |
| GPS 端口 | 使用实际连接 D20 的 UART |
| 波特率 | 115200 |
| 协议 | GPS 自动识别或 UBX |
| 定位检查 | 起飞前确认 GPS 状态稳定 |

## 验证

在 QGroundControl 中观察 GPS 状态：

- 卫星数持续刷新。
- 经纬度和高程正常。
- HDOP/VDOP 无异常。
- RTK 状态能够进入 Float 或 Fixed。

若 PX4 无法识别 D20，请先回到 PC 侧确认 D20 当前为无人机版固件并有 UBX/u-blox 协议输出，再检查飞控串口参数和 TX/RX 接线。
