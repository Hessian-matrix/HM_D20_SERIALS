# RTK工作方式与手册结构

HM RTK系列包含D20四臂螺旋形态和D13蘑菇头形态，两个系列均提供4G与LoRa版本。四个RTK SKU都是移动站产品；LoRa SKU按套件交付，并包含配套D13 LoRa基站及附件。

## 共同工作方式

1. 设备接收GPS、北斗、Galileo、QZSS、GLONASS和IRNSS卫星信号。
2. 设备通过4G/CORS或本地LoRa链路获得差分数据。
3. 设备内部完成RTK解算。
4. 设备通过UART向飞控、机器人主控、Viobot2或PC输出定位结果。

LoRa差分数据在基站和移动站内部链路中传输，不作为外部用户接口。

## 4G与LoRa

| 选择 | 4G版本 | LoRa版本 |
| --- | --- | --- |
| 差分来源 | CORS/NTRIP服务 | 套件内D13 LoRa基站 |
| 网络要求 | 需要蜂窝网络、SIM卡和CORS账号 | 不依赖公网 |
| 现场设备 | 单个移动站 | 移动站 + 配套基站 |
| 适合场景 | 跨区域、分散作业 | 固定区域、自建链路 |

## 地面版与无人机版固件

通信版本决定差分数据从哪里来，固件版本决定定位结果如何向下游输出：

- 地面版固件：默认10 Hz NMEA，面向Viobot2、机器人主控和PC。
- 无人机版固件：默认10 Hz UBX，面向AMP、PX4等飞控。

详细选择和修改边界见[固件与输出协议选择](05-基本使用/固件与输出协议选择.md)。
