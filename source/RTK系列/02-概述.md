# 概述

D20 系列是一款集成四臂螺旋 GNSS 天线、高精度定位模组、地磁罗盘传感器以及 4G 或 LoRa 通信模组的一体化 RTK 定位终端，支持 L1 + L5 双频 RTK。

设备采用对称式四臂螺旋结构，具备 360° 全向接收能力和宽波束圆极化特性，对低仰角卫星信号有较好的接收效果。内置 GNSS 定位模组支持 GPS、北斗、GLONASS、Galileo 等主流卫星导航系统，在具备差分链路和良好天空视野的条件下，可输出厘米级 RTK 定位结果。

D20 提供 4G 版本和 LoRa 版本：

- 4G 版本通过公网接入 NTRIP/CORS 差分服务，适合有蜂窝网络覆盖、需要远距离或跨区域作业的场景。
- LoRa 版本通过本地基站向移动站发送差分数据，适合无公网覆盖、固定作业区域和自建基站场景。

D20 通过底部 8Pin GH1.25 接口完成供电和串口通信，可接入无人机飞控、机器人主控、Viobot2 或 PC 上位机。典型应用包括无人机定位、地面机器人、精准农业、手持终端、资产管理和物联网传感网络。
