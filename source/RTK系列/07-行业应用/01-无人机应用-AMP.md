# 无人机应用-AMP

D20 接入 AMP 飞控时，应使用 D20 无人机版固件。无人机版固件默认输出 10 Hz UBX 定位数据，用于飞控 GPS 接口识别和 RTK 状态解析。接入前请先在 PC 上确认 D20 能够正常输出固定解，再连接到飞控。

固件选择见[固件与输出协议选择](../05-基本使用/固件与输出协议选择.md)，完整8-pin定义见[D20接口与接线](../05-基本使用/D20接口与接线.md)。

## 固件版本

| 项目 | 要求 |
| --- | --- |
| D20 固件 | 无人机版固件 |
| 主要输出协议 | 默认 10 Hz UBX |
| 差分链路 | 按现场条件选择 4G 版本或 LoRa 版本 |

## 硬件连接

1. 将 D20 安装在无人机顶部开阔位置。
2. 将通信天线固定牢靠，避免桨叶、碳板和大电流线缆遮挡或干扰。
3. D20 TX 接飞控 GPS/UART RX。
4. D20 RX 接飞控 GPS/UART TX。
5. D20 GND 与飞控 GND 共地。
6. 使用 5 V ±0.5 V 供电，确认飞控接口供电能力满足 D20 要求。

## 飞控侧配置

飞控侧应按 GPS 接入方式配置对应串口：

| 项目 | 推荐值 |
| --- | --- |
| 串口协议 | GPS / UBX |
| 波特率 | 115200 |
| 数据输入 | UBX 定位数据 |
| 更新频率 | 默认 10 Hz，最高 20 Hz；需与飞控接收能力一致 |

## 验证

1. 上电后确认飞控地面站能识别 GPS。
2. 确认卫星数、经纬度、高程持续刷新。
3. 在开阔环境等待定位状态进入 RTK Float 或 RTK Fixed。
4. 解锁飞行前，确认定位状态稳定且航向、速度等字段无异常跳变。

无法进入Fixed时，按[RTK状态与Fixed验证](../05-基本使用/RTK状态与Fixed验证.md)检查差分链路和现场条件。
