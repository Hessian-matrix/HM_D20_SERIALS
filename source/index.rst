HM 定位产品资料中心
======================================

这里集中提供 Hessian Matrix RTK 与 GNSS 产品的选型、首次使用、系统集成和故障排查资料。
如果尚未确定产品，先进入产品选型；如果已经收到设备，直接按产品进入首次使用流程。

从这里开始
----------------

.. list-table::
   :class: documentation-entry-grid
   :widths: 33 33 34

   * - **选择产品**

       查看 D20、D13 与 G51B 的定位能力、通信方式和适用场景。

       :doc:`进入产品选型 <产品矩阵/index>`
     - **首次使用**

       按已购买的 RTK 或 GNSS 产品完成接线、配置和首次定位验证。

       :doc:`RTK 快速开始 <RTK系列/01-快速开始/index>`
     - **集成与支持**

       查找飞控、机器人、Viobot2 接入方法，以及参数维护和故障排查资料。

       :doc:`查看行业应用 <RTK系列/07-行业应用/index>`

产品范围
----------------

.. list-table::
   :class: portfolio-summary
   :header-rows: 1
   :widths: 22 28 28 22

   * - 产品
     - 产品形态
     - 差分 / 定位方式
     - 主要入口
   * - **HM-D20-4G**
     - 四臂螺旋 RTK 移动站
     - 4G 接入 CORS/NTRIP

   * - **HM-D20-LoRa**
     - 四臂螺旋 RTK 移动站套件

     - :doc:`RTK 快速开始 <RTK系列/01-快速开始/index>`
   * - **HM-D13-4G**
     - 蘑菇头 RTK 移动站
     - 4G 接入 CORS/NTRIP
     - :doc:`产品选型 <产品矩阵/index>`
   * - **HM-D13-LoRa**
     - 蘑菇头 RTK 移动站套件
     - 配套 D13 LoRa 基站
     - :doc:`RTK 快速开始 <RTK系列/01-快速开始/index>`

     - 单频 GNSS 一体化模组
