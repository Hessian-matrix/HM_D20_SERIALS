产品范围
----------------

.. list-table::
   :class: portfolio-summary
   :header-rows: 1
   :widths: 22 28 28 22

   * - 产品
     - 产品形态
     - 差分 / 定位方式
     - 主要入口
   * - **HM-D20-4G**
     - 四臂螺旋天线一体化 RTK 接收机
     - 4G 接入 CORS/NTRIP
     - :doc:`查看产品 <products/models/hm-d20-4g>`
   * - **HM-D20-LoRa**
     - 四臂螺旋天线 RTK 定位套件
     - 配套 D13 LoRa 基站
     - :doc:`查看产品 <products/models/hm-d20-lora>`
   * - **HM-D13-4G**
     - 紧凑型一体化 RTK 接收机
     - 4G 接入 CORS/NTRIP
     - :doc:`查看产品 <products/models/hm-d13-4g>`
   * - **HM-D13-LoRa**
     - 紧凑型一体化 RTK 定位套件
     - 配套 D13 LoRa 基站
     - :doc:`查看产品 <products/models/hm-d13-lora>`
   * - **HM-G51B**
     - 单频多星座 GNSS 接收机模组
     - 独立 GNSS 定位
     - :doc:`查看产品 <products/models/hm-g51b>`

HM-D20-LoRa 和 HM-D13-LoRa 均按套件销售，包含配套 D13 LoRa 基站及配件；基站不单独销售。
