# HM-D13-4G

面向地面移动作业的蘑菇头双频 RTK 移动站，内置 GNSS 与 4G 通信天线，通过蜂窝网络接入 CORS/NTRIP。

```{image} ../image/d13.png
:alt: HM-D13-4G 蘑菇头 RTK 移动站
:class: sku-product-image
```

## 核心价值

- **一体化蘑菇头形态**：GNSS 与4G天线集成在设备内部，外部安装简洁。
- **无需本地基站**：通过4G接入CORS/NTRIP，适合跨区域和分散作业。
- **单接口接入主机**：外部5-pin航空接口完成供电、UART和PPS连接。
- **按应用交付固件**：可按地面设备或无人机用途配置NMEA/UBX输出。

## 工作方式

![HM-D13-4G通过4G接入CORS](../image/scenarios/d13-4g-ref-v2.png)

设备接收GNSS卫星信号，并通过4G网络获取CORS/NTRIP差分数据；完成RTK解算后，通过5-pin航空接口向外部设备输出定位结果。

## 交付组成

- HM-D13-4G移动站。
- 配套供电与串口线缆，具体以订单和装箱清单为准。

用户需要自行准备有流量的Nano-SIM卡、可用的CORS/NTRIP账号和蜂窝网络覆盖。

## 关键参数

| 项目 | 参数 |
| --- | --- |
| 定位类型 | L1/L5双频RTK |
| RTK精度 | 水平1.0 cm + 1 ppm；垂直1.5 cm + 1 ppm |
| 默认输出 | 地面版10 Hz NMEA；无人机版10 Hz UBX |
| 最高更新率 | 20 Hz |
| 主接口 | 5-pin 航空接口；外部 UART IO 3.3 V；默认 115200 bps |
| 供电 | 5 V ±0.5 V（4.5–5.5 V） |
| 尺寸 / 重量 | Φ152 × 67.9 mm / 255 g |
| 工作 / 存储温度 | -40–85 °C / -50–105 °C |

完整GNSS频点、灵敏度、动态条件和LTE频段请查看[产品对比与资料](../概述.md)。

## 外部接口

- **5-pin航空接口**：供电、UART收发和PPS信号。
- **Nano-SIM卡槽**：位于顶壳内部。
- **USB-C配置口**：位于顶壳内部，用于写入CORS/NTRIP账号。

安装或更换SIM卡、连接配置口时需要打开顶壳；完成操作后应恢复设备结构并确认装配可靠。

## 适用场景与前提

适合测绘、精准农业、智能驾驶测试、地面机器人和其他稳定安装的移动作业。现场需要蜂窝网络覆盖；SIM卡流量和CORS/NTRIP服务由用户管理。
