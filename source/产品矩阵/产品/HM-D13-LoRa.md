# HM-D13-LoRa

面向固定区域和无公网作业的蘑菇头双频 RTK 套件，由 D13 LoRa 移动站、配套专用 D13 LoRa 基站硬件及附件组成。

```{image} ../image/d13.png
:alt: HM-D13-LoRa 蘑菇头 RTK 移动站
:class: sku-product-image
```

## 核心价值

- **本地自建差分链路**：不依赖公网、流量卡或CORS账号。
- **出厂默认配对**：基站和移动站上电自动连接，减少现场通信配置。
- **适合稳定地面安装**：蘑菇头移动站内置LoRa天线，外部只需连接5-pin接口。
- **支持多移动站协同**：一个基站可一对一或一对多服务移动站。

## 工作方式

![HM-D13-LoRa移动站与D13基站组成差分系统](../image/scenarios/d13-lora-ref.png)

D13基站固定接收卫星信号，通过内部LoRa链路向D13移动站发送差分数据；移动站完成RTK解算后，通过5-pin航空接口向外部设备输出定位结果。

## 交付组成

- HM-D13-LoRa移动站。
- 配套专用 D13 LoRa 基站硬件。
- 基站天线、供电线缆和安装配件，具体以装箱清单为准。

专用 D13 LoRa 基站硬件仅随 LoRa 套件提供，不单独销售，也不作为移动站使用。

## 关键参数

| 项目 | 参数 |
| --- | --- |
| 定位类型 | L1/L5双频RTK |
| RTK精度 | 水平1.0 cm + 1 ppm；垂直1.5 cm + 1 ppm |
| 默认输出 | 地面版10 Hz NMEA；无人机版10 Hz UBX |
| LoRa | 850–930 MHz；出厂默认915 MHz |
| 链路拓扑 | 单基站；一对一或一对多；最多4096个移动站 |
| 标称距离 | 最远约6 km；未完成我方实测，非现场保证距离 |
| 移动站接口 | 5-pin 航空接口；外部 UART IO 3.3 V；默认 115200 bps |
| 供电 | 5 V ±0.5 V（4.5–5.5 V） |
| 尺寸 / 重量 | 移动站：Φ152 × 67.9 mm / 236 g；基站：Φ152 × 67.9 mm / 515 g |

完整GNSS、环境和动态参数请查看[产品对比与资料](../概述.md)。

## 外部接口

- **D13移动站5-pin航空接口**：供电、UART收发和PPS信号。
- **D13基站2-pin USB供电口**：连接5 V ±0.5 V外部电源。
- **D13基站通信天线接口**：连接基站外置LoRa天线。

## 适用场景与前提

适合测绘、精准农业、园区机器人、智能驾驶测试和固定区域多终端作业。基站需要开阔、稳定架设，上电后不得移动；同一局部场景只能使用一个基站。
