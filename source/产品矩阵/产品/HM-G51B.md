# HM-G51B

:::{admonition} 产品定位
:class: page-summary

**面向普通卫星定位和紧凑型终端集成的单频 GNSS 一体化模组。** 通过 UART 输出 UBX-NAV-PVT 定位数据，不需要差分基站或 CORS 服务。
:::

## 核心价值

- **定位链路简洁**：无需 4G、LoRa、CORS 账号或本地基站。
- **紧凑轻量**：模组尺寸 26.5 × 35.5 × 7.1 mm，重量 10 g。
- **多星座单频接收**：支持 GPS、北斗、Galileo、QZSS 和 GLONASS 的 L1 频段信号。
- **便于主机集成**：通过 UART 输出 UBX-NAV-PVT 数据，默认波特率 115200 bps。
- **集成磁力计**：内置 QMC5883L，通过 I2C 接口连接主机。

## 工作方式

HM-G51B 接收 GNSS 卫星信号并完成普通单点定位，通过 UART 向飞控、车载设备、资产定位终端或嵌入式主控输出 UBX-NAV-PVT 数据。它不属于 RTK 差分定位产品。

:::{note} 产品边界
HM-G51B 提供普通单点定位，**不属于 RTK 差分定位产品**。需要厘米级定位时请选择 HM-D20 或 HM-D13 系列。
:::

## 关键参数

| 项目 | 参数 |
| --- | --- |
| 定位类型 | L1 单频 GNSS |
| 接收频点 | GPS L1、北斗 B1、Galileo E1、QZSS L1、GLONASS G1 |
| 跟踪通道 | 120 |
| 定位精度 | 1.5 m CEP |
| 启动时间 | 冷启动 28 s；热启动 1 s |
| PVT 最高更新率 | 20 Hz |
| 输出 | UART / UBX-NAV-PVT；默认 115200 bps |
| 磁力计 | QMC5883L；I2C 接口 |
| 工作电压 | 4.0–5.5 V；典型 5 V |
| 工作电流 | @ 5 V：最小 25 mA；典型 28 mA；最大 30 mA |
| 尺寸 / 重量 | 26.5 × 35.5 × 7.1 mm / 10 g |
| 工作 / 存储温度 | -40–85 °C / -50–105 °C |

完整灵敏度、速度和时间参数请查看[产品对比与资料](../概述.md)。

## 外部接口

HM-G51B 使用 6-pin MX1.25 mm 接口，提供电源、UART 和磁力计 I2C 信号；接口不提供 PPS 引脚。

## 适用场景与前提

适合车载导航、车队管理、资产追踪、AVL/LBS、无人机普通定位和紧凑型终端。需要厘米级定位或差分链路时，应选择 HM-D20 或 HM-D13 系列。
