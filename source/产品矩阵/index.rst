产品选型
======================================

本页用于快速确定产品形态和通信链路。需要核对完整规格时，再进入“产品对比与资料”；
已经收到设备时，可直接进入相应用户手册。

产品矩阵概览
----------------

我们的定位产品分为 RTK 系列和 GNSS 系列。RTK 是当前主系列，包含 D20、D13 两种产品形态，
并分别提供 4G 和 LoRa 两种差分链路；GNSS 系列当前提供 HM-G51B。

RTK 系列
~~~~~~~~~~~~~~~~

RTK 产品将 GNSS 天线、定位计算模组和通信链路集成在一起，通过标准接口直接输出定位结果，
减少外部器件、线缆和系统配置，适合快速集成到无人机、机器人、车辆和其他移动设备中。

RTK 系列包含两个产品系列：

* **D20 系列：四臂螺旋天线**，体积小、重量轻，适合无人机、机器人和车载设备等对安装空间、重量和航向能力敏感的移动平台。
* **D13 系列：蘑菇头天线**，适合地面移动站和固定区域作业；LoRa 套件配有 D13 基站，可用于测绘、精准农业和多终端协同。

两个系列都提供 4G 和 LoRa 两类一体化通信链路。下表只用于快速理解产品与链路的对应关系。

GNSS 系列
~~~~~~~~~~~~~~~~

GNSS 系列目前以 HM-G51B 为代表，面向不需要 RTK 差分链路的普通卫星定位和紧凑型终端集成场景，
适用于资产追踪、车载导航、紧凑型终端和对成本、尺寸、集成复杂度更敏感的应用。

* :doc:`查看 HM-G51B <产品/HM-G51B>`

怎么选择
----------------

1. **先看定位能力**：需要厘米级定位时选择 RTK 系列；只需要普通单频 GNSS 定位时选择 HM-G51B。
2. **再看安装形态**：对重量、空间和无人机集成更敏感时优先选择 D20；需要蘑菇头形态或地面移动站时选择 D13。
3. **最后选差分链路**：有稳定蜂窝网络和 CORS/NTRIP 服务时选择 4G；希望本地自建、不依赖公网时选择 LoRa 套件。

D13 LoRa 基站不单独销售，只随 HM-D20-LoRa 或 HM-D13-LoRa 套件提供。
